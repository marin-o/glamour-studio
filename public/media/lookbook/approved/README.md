# Approved owner Lookbook media

These eight JPEGs are owner-supplied photographs copied byte-for-byte from
`lookbook0.jpg` through `lookbook7.jpg` on 2026-10-06. The owner approved
public website use and recognizable-person consent for this set. The files are
presented in numeric
order and are described by the bilingual alt text in `src/lib/lookbook-media.js`.

The source pixels are preserved. A nested EXIF/IFD review found only image
orientation, dimensions, and color-space fields (plus an embedded thumbnail in
one source); no GPS fields, names, timestamps, or other personal identifiers
were present. The copies retain the source metadata because no sensitive fields
were found.

The `/lookbook` route remains `noindex` as a separate search-indexing decision.
This directory uses the same responsive `next/image` delivery contract as the
rest of the site: intrinsic dimensions are generated by
`scripts/media/lookbook-manifest.mjs`, and source JPEGs are requested at
quality 100. Run `pnpm media:optimize` after changing this set.
