# glamour-studio Design System Bridge

Root `DESIGN.md` is the authoritative visual-system contract for this
repository. This file exists only as a compatibility pointer for older
Sitewright workflows and should not grow a second design source of truth.

Design work should start from `DESIGN.md`, then inspect implementation files
named by `REPO_MAP.md` and the active task. If a durable visual rule, token,
component behavior, motion role, media rule, or anti-pattern changes, update
`DESIGN.md` in the same task.
