# 0000 - Record Architecture Decisions

Status: Accepted

## Context

Consequential technical choices need their original requirements and tradeoffs
to survive beyond chat history.

## Decision

Record an ADR before adopting or replacing a major runtime dependency, renderer,
content system, state model, or cross-cutting architectural boundary.

## Consequences

Agents may rely on accepted ADRs and should not casually relitigate them. A new
ADR may supersede an old one when requirements genuinely change.
